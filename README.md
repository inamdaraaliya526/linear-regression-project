# Student Marks Prediction Using Linear Regression

## Aim
To predict student marks based on the number of hours studied.

## Dataset
The file `data.csv` contains study hours and marks for 8 sample students.

## Method
The Python program reads the CSV file and calculates the slope and intercept of a linear regression line. It uses that line to predict marks for 6.5 study hours.

## How to run
Make sure `data.csv` and `linear_regression.py` are in the same folder, then run:

```bash
python linear_regression.py

```

## Example result
For the sample data, the predicted marks for 6.5 study hours are about **74.76**.

## Files
- `data.csv` — sample study hours and marks
- `linear_regression.py` — regression calculation and prediction
- `README.md` — project information
